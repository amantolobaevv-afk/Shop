# AMAN BREND

Статический сайт магазина мужской одежды в Бишкеке.

## Запуск

Откройте `index.html` в браузере либо запустите любой статический HTTP-сервер из корня проекта, например `python -m http.server 8080`.

## Возможности

- Каталог из 12 демонстрационных товаров, категории, сортировка и выбор размера.
- Корзина и оформление сообщения для WhatsApp.
- Локальное управление товарами, загрузка фото, экспорт и импорт каталога.
- Контакты, бренды, доставка, гарантия и информация о магазине.
- Светлая и тёмная темы; частичный перевод RU / KY / EN / UZ.

## Ограничения

Это демонстрационная клиентская версия. Каталог и корзина хранятся в localStorage текущего браузера; при запуске через file:// хранение может различаться между страницами. Для общего каталога нужны сервер и база данных. Управление товарами не является защищённой административной панелью. Онлайн-оплата не подключена. Заказ отправляется пользователем через WhatsApp; серверного учёта заказов нет.

Фото демонстрационные и загружаются из внешних источников. Для реальных продаж замените их своими фотографиями и подтвердите цены и наличие. Товары, добавленные через браузер, нужно отдельно экспортировать в JSON; они не входят в этот репозиторий.

## Структура

`index.html` — главная; `catalog.html` — каталог; `contact.html`, `brands.html`, `delivery.html`, `warranty.html`, `about.html` — информационные страницы. `app.js`, `manage.js`, `navigation.js` — логика; `style.css` и `atelier.css` — оформление.
